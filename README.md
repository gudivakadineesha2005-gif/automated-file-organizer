## 📌 Description
This Python script automatically organizes files in a given folder into categorized subfolders based on file extensions. It sorts Images, Documents, Videos, Music, Archives, and Code files.

## 🚀 How to Run
1. Make sure Python 3.x is installed
2. Clone this repo or download `main.py`
3. Run: `python main.py`
4. Enter the full folder path when prompted
5. Files will be moved to categorized folders automatically

## ⚙️ Features
- Sorts 6 file categories: Images, Documents, Videos, Music, Archives, Code
- Auto-creates folders if they don't exist
- Error handling for invalid paths
- Prints progress for each file moved
